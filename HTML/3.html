What it actually does

打开看了才知道，
它其实挺能干。

下面每一条都来自站点界面本身，不是脑补的卖点。

01 / PASTE
📋

粘贴完整 HTML 就发

主界面第一行就写着「粘贴完整 HTML 代码，或选一个模板快速开始」——直接把整页代码丢进去。

02 / TEMPLATES
🧩

四个模板，不用从零写

空白页 · 公告页 · 跳转页 · 名片页，四种常见需求一键起手，改几个字就能用。

03 / PREVIEW
👁

发布前先预览

界面里有独立的「预览」入口，先确认长什么样，再决定要不要发出去。

04 / URLS
🔗

两种网址随你选

子域名模式生成 xxx.ohdep.us.ci；路径模式为 /s/xxx.html。

05 / CONTROL
⚙️

发布设置不是摆设

标题、有效期、访问密码、收录控制 —— 什么时候失效、谁能看、要不要被搜到，都能定。

06 / LOCAL
💾

记录留在自己浏览器

发布记录存在本机 localStorage，编辑、恢复与删除都从同一个页面操作。

Three steps

从上头到上线，三步。

  1. 粘贴，或者挑模板

    完整 HTML 直接贴；懒得写就点空白页 / 公告页 / 跳转页 / 名片页。

  2. 预览 + 设好发布项

    看一眼效果，再填标题、有效期、访问密码，决定要不要允许收录。

  3. 发布，拿链接发出去

    选子域名或路径模式，得到一条能直接发给别人的网址。

The quiet part

所以，为什么没人知道？

它把该做的都做完了，就是没学会大声介绍自己。
